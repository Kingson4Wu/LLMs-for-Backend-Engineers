# 第一部分：数学与机器学习基础

大模型并不脱离数学与机器学习规律。本部分围绕三个问题组织内容：信息怎样表示为向量，分数怎样变成概率，误差怎样改变参数。它们构成一条连续的计算链：

它在[全书的主线图](../index.md#全书的主线图)中对应“可学习计算”的起点：这里解释符号、分数和误差怎样成为后续模型训练与推理都要使用的语言。

**token 和上下文 → 向量表示 → 分数与概率 → 损失 → 梯度更新参数**

这条链解释离散符号怎样进入计算、模型怎样在候选输出间选择，以及训练怎样把误差写入参数。

| 小分类 | 要理解什么 | 从哪里开始 |
| --- | --- | --- |
| 全景与表示 | AI 怎样成为优化问题，离散符号怎样成为向量 | [AI 的数学与机器学习基础](../chapters/part1-math-foundations/ai-math-foundations.md)、One-hot 与 Embedding、点积 |
| 分数与选择 | 分数怎样变成概率，非线性为何必要 | Softmax、激活函数 |
| 学习与稳定 | 误差怎样产生更新方向，深层训练为何会不稳定 | 感知机、交叉熵、反向传播、梯度 |

可以按目录阅读，也可以从需要的环节进入：表示章节解释离散符号和向量关系，概率章节解释选择，学习章节解释参数更新和训练稳定性。完成本部分后，应能说明参数为什么能够表示关系，以及训练为什么能沿着误差改变参数。
