# 第二部分：LLM 内部原理

这一部分回答两个相连的问题：**参数怎样从训练中形成能力，已有参数又怎样在一次请求中把输入变成输出？**训练、架构和生成对应同一模型在不同时间尺度上的机制。

在[全书的主线图](../index.md#全书的主线图)中，这一部分连接“可学习计算”和应用中的一次调用：它只讨论模型内的参数与计算，不把外部事实或执行结果误写成模型自身能力。

| 小分类 | 要理解什么 | 从哪里开始 |
| --- | --- | --- |
| 能力形成与适配 | 参数怎样从数据学习，并怎样针对特定任务调整 | [模型的能力是怎样训练出来的](../chapters/part2-llm-internal/model-training-lifecycle.md)、优化器、微调与蒸馏 |
| 表示与计算 | Token 表示怎样经历序列建模、上下文交换和深层变换 | Embedding 演化、RNN 到 Transformer、Transformer、缩放点积、残差、LayerNorm |
| 生成与扩展 | 模型怎样逐步产生输出，以及语言和模态怎样共享或扩展表示 | LLM 生成机制、推理不确定性、多语言、多模态 |

目录按“训练—表示与计算—生成与扩展”安排，但每个小分类都能独立进入。本部分描述模型内部的统计计算和参数状态，不把当前事实、授权或外部执行混入模型能力本身。
