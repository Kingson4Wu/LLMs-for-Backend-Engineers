# LayerNorm：怎样保持表示的数值稳定

神经网络训练的过程，看起来是在“学习语义”或“理解结构”，但在更底层，它其实是一件非常朴素的事情：
**一层一层地传递和变换数字。**

中间数值的尺度和分布是训练不稳定、梯度异常或不收敛的常见原因之一；数据、初始化、优化器、学习率和数值精度也都会影响训练。

> **中间数值的尺度失控了。**

LayerNorm（Layer Normalization）正是为了解决这个问题而出现的。但要真正理解它，不能从公式开始，而必须先回到一个更基础的问题：**什么是归一化，神经网络为什么需要归一化**。

---

## 什么是归一化

先从一个生活中的例子出发。

假设你要比较两次考试成绩：
* 一次考试满分 150
* 另一次考试满分 100

你不能直接比较 120 分和 80 分谁更好，因为它们的**尺度不同**。

一个更合理的做法是：
* 减去平均值
* 再除以标准差

这样得到的数值不再依赖原始分数范围，而只反映**相对水平**——平均值约为 0，波动程度约为 1。

这就是归一化（Normalization）的本质思想：

> **先按当前样本的统计量重新标定尺度，使不同量纲的数值可以比较。**

---

## 神经网络为什么需要归一化

回到神经网络。神经网络的基本操作是反复进行线性变换：

$$
y = Wx + b
$$

如果输入 $x$ 的尺度稍微偏大，权重 $W$ 没有被精细约束，那么输出 $y$ 很容易比 $x$ 更大或更小。

当层数不断增加时：

```
x → y → z → u → …
```

哪怕每一层只“放大或缩小一点点”，结果也会变成：
* 激活值越来越大（数值爆炸）
* 或越来越小（数值消失）

这就像一张图片被反复复印：复印次数一多，画面一定会失真。

于是，一个非常直接但极其重要的工程直觉出现了：

> **能不能在每一层之间，把数值拉回到一个“正常范围”？**

这正是神经网络中各种 Normalization 方法存在的根源。

---

## LayerNorm 在归一化什么

在 Transformer 中，每个 token 在某一层都会被表示成一个向量：

$$
x = (x_1, x_2, \dots, x_d)
$$

这 $d$ 个数一起，构成了模型在当前层对这个 token 的全部状态描述。

LayerNorm 的做法非常明确：

* **不看其他 token**
* **不看 batch**
* **只对当前这个 token 自己的向量做归一化**

具体来说，它会在特征维度（hidden dimension）上计算均值和方差：

$$
\mu=\frac{1}{d}\sum_{i=1}^{d}x_i
$$

$$
\sigma=\sqrt{\frac{1}{d}\sum_{i=1}^{d}(x_i-\mu)^2+\epsilon}
$$

然后进行标准化，并加上可学习的缩放与平移参数：

$$
\text{LN}(x)_i=\gamma\cdot\frac{x_i-\mu}{\sigma}+\beta
$$

归一化之后，向量的均值约为 0、方差约为 1，但通过 $\gamma$ 和 $\beta$，模型仍然可以学习合适的尺度。

一句话总结：

> **LayerNorm 是对“每一个 token 自己的向量”做归一化，完全不依赖其他 token 或 batch。**

---

## Transformer 为什么容易出现数值不稳定

理解了归一化之后，再看 Transformer 的结构，就会发现：注意力、残差和深层堆叠都会让数值尺度与梯度传播成为需要专门处理的问题。

原因来自三个叠加的结构性因素：

### 1. Attention 的输出不以控制特征尺度为目标

Attention 的输出形式是：

$$
y_i=\sum_j \alpha_{ij} v_j
$$

这里的权重经过 Softmax 后非负且和为 1，因此对 Value 向量是加权平均；但 Value 本身的尺度、投影矩阵和后续残差并不由这一步保证。它的目标是**混合信息**，不是把每层特征的尺度调到适合下一层的范围。

### 2. 残差连接会层层累加数值

Transformer 中每一层都有残差结构：

$$
x_{l+1} = x_l + f(x_l)
$$

残差提供直接的信息与梯度通路，但它也会把新变换叠加到旧表示上；若没有合适的初始化、归一化或缩放，尺度可能随层数漂移。

一个常见的误解是把 residual 当作“稳定器”。更准确的说法是：

> **Residual 负责信息通路，但并不负责数值稳定。**

### 3. Softmax 对尺度极其敏感

Attention 内部使用 Softmax。logit 尺度过大时，分布会过于尖锐、许多位置的梯度变小；尺度过小时，分布会接近均匀、区分能力变弱：
* 输入过大 → 接近 one-hot → 梯度几乎为 0
* 输入过小 → 接近均匀分布 → 注意力失效

**Transformer 同时包含 Attention 的信息混合、Residual 的数值叠加与 Softmax 的尺度敏感性。归一化是让这些模块更容易稳定协作的重要手段，但并非唯一条件。**

---

## LayerNorm 怎样稳定表示

LayerNorm 的作用可以概括为一句话：

> **在每一层，把每个 token 的表示拉回到同一个稳定的统计坐标系。**

它在 Transformer 中的分工可以用这张图来理解：

```
输入 token 向量 x
        |
        v
   [ Attention ]        <- 看别人：混合信息
        |
        v
      f(x)
        |
        +-------------------+
        |                   |
        v                   |
   [ Residual: x + f(x) ]   <- 保自己：信息不断
        |
        v
   [ LayerNorm ]            <- 稳自己：归一化、控数值
        |
        v
     交给下一层
```

三者的职责是：
* **Attention 管信息交流**
* **Residual 管信息传承**
* **LayerNorm 管数值纪律**

LayerNorm 带来的直接效果包括：
* 让每层看到更可控的输入尺度
* 减少表示随层数无控制漂移的风险
* 配合缩放点积，帮助 Softmax 保持有用的区分度
* 改善深层网络中的梯度传播条件

因此可以说：

> **LayerNorm 不是可训练 Transformer 的充分条件，却是许多 Transformer 结构中稳定深层训练的关键组件。**

---

## 为什么 Transformer 通常不用 BatchNorm

在讨论 LayerNorm 时，BatchNorm 经常被拿来对比。它们同属“归一化家族”，但适用场景完全不同。

BatchNorm 的核心思想是：

> **利用一个 batch 内所有样本的统计量来做归一化。**

这在 CNN 中很常见；对 Transformer 的可变长度序列和自回归推理而言，它通常不如 LayerNorm 方便：

**1. Batch 本身不稳定**
* 句子长短不同
* padding 复杂
* 推理时常常 batch = 1

**2. Token 不应被迫参考其他样本**

BatchNorm 的统计量会让一个 token 的数值受同一批其他样本（以及实现中统计范围）的影响；在小 batch、变长序列和单请求推理时，这种依赖不够自然。LayerNorm 则按单个位置的特征维度计算，训练与推理的形式也一致。

典型 Transformer 的 LayerNorm 不看 batch，也不混合其他 token，只对当前位置的隐藏特征做校准。

一句话总结区别：

> **BatchNorm 在“群体里”找尺度，LayerNorm 对“自己”做校准。**

Transformer 需要的是后者。

---

## 小结：LayerNorm 在层中的位置

LayerNorm 并不是 Transformer 的“附加技巧”，而是**归一化思想在序列建模中的一次精准落地**：

* 以 token 为基本单位
* 不依赖 batch
* 不混淆语义交互与数值校准

它让 Transformer 能在极深的结构中，始终保持数值可控、梯度可传、注意力可学习。
