## 实际验收

- Python：12 项测试通过，含真实 HTML/EPUB 导出、目录和语言回退回归、链接/锚点、暂存资源、产物来源、发行校验、翻译过期与 PDF 缺字检查。
- 网站：5 项 Node 测试通过；Astro 检查 0 errors / 0 warnings（17 条类型推断 hints）。
- 路径：根路径和 `/LLMs-for-Backend-Engineers/` 均构建并验证通过；双语共 68 个 HTML 页面、约 3,000 个本地引用。文件数量包含离线打印版及兼容页。
- 浏览器：Chromium 实测数学公式、字号、主题保存、专注模式、笔记/高亮保存与刷新恢复、备份导出、语言隔离、中文和英文搜索、历史锚点、390px 手机布局及关闭 JavaScript 的基本阅读；无脚本异常或本地资源 HTTP 错误。复审另验证跨段落选文高亮。
- 旧站：Honkit 升级至 6.2.2 并更新传递依赖，实际构建通过，20 个内容页；旧网站链接及 250 个历史标题 ID 已核对。新版网站和旧 Honkit 两套 npm audit 均为 0 vulnerabilities。
- 出版：中文 PDF 94 页、英文 PDF 101 页；检查封面、标题页、目录与正文样张；最终无缺字警告，字体已嵌入。中英各 3 种格式 SHA256 与清单一致，同语言来源摘要一致。
- EPUB：EPUBCheck 5.4.0 对两种语言均报告 0 fatal / 0 error / 0 warning。
- 翻译：20 对文档的标题层级、代码围栏及 Python AST 一致；英文正文无未翻译中文，所有目录来源和源 hash 检查通过。技术澄清见英文 `review-notes.md`。
- 审查：出版规格与代码质量分开复审；网站/旧链接/工作流复审发现的问题已修复。未在 GitHub 托管环境实际运行 Actions。

## 边界与维护要求

英文尚需人工编辑审校；源 hash 仅表明版本对应，不保证语言或技术结论正确。英文中的数字纠正与技术措辞澄清保留在审校记录中，未据此批量改写中文正文。

main 的 Pages 构建生成 HTML/EPUB，不依赖 TeX；PDF 由独立 tag 发行流程提供。旧 PDF URL 仅在站点构建含真实中文 PDF 时保留。本地下载可直接使用 `book/exported/{zh-Hans,en}/`。

浏览器笔记没有云同步，清理站点数据前应导出。EPUB 标准校验不能替代各电子阅读器的人工排版验收。论文式技术内容与全部示例执行不属于本次平台验收。

没有擅自添加许可证、提交、推送、tag、Release 或 Pages 发布。参考项目未修改。原有发布日期元数据保留；本地 manifest 如实记录 dirty 状态，正式发行必须来自干净 tag。
