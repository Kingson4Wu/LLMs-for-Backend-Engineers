## 发现与修正

| 问题 | 修正 |
| --- | --- |
| 两版前言称项目“开源”，但仓库没有选定许可证 | 改为公开托管，并明确尚未确定内容/代码许可；同步英文及前言源 hash |
| 英文导读/前言把工具调用、Agent 写入现有内容，随后又说尚未收录 | 与中文统一：当前第三层覆盖 RAG、检索与重排，其余为规划 |
| 旧调研仍称“尚未迁移”，计划示例仍为英文 draft | 保留历史证据，增加明确的基线说明及当前验收入口；不把旧缺陷当成当前状态 |
| 多个命令块反复 `cd web`，测试依赖与副作用没有说明 | README/开发指南改用仓库根目录下的 `npm --prefix`；贡献指南补齐依赖安装、英文校验，并说明测试会重建中文 HTML/EPUB |
| macOS/Linux 字体被简化为同一套，精简 TeX 的依赖缺漏 | 列出中英默认字体、配置与环境变量优先级、CI 的 Noto 覆盖，以及模板依赖；说明本地分页不是 CI 页数承诺 |
| “所有格式摘要一致”“干净 tag”混淆语言与打包器职责 | 明确同语言三格式来源一致，跨语言摘要不同；本地命令只打包，tag/发布由工作流负责 |
| “不可变发行”容易被理解成 GitHub 平台强制锁定 | 工作流步骤改称不覆盖既有 Release，文档明确未启用平台不可变设置 |
| main 部署说明省略路径筛选、fork 限制与 PDF 分工 | 按工作流补齐实际触发路径、目标目录、上游仓库条件及 Pages/Release 分工 |
| 下载页“下载本次构建”可能暗示出版物刚由网站构建生成 | 改为“下载此文件”，指向各文件来源清单；说明网站只复制已有出版物、书稿变更后需先重建 |
| 笔记备份与语言状态描述不够具体 | 明确每语言每文章备份、origin 隔离、选文失配处理；published 不等于人工审校或远端已部署 |

同时说明主站/出版/旧站样式的实际入口、书籍发布日期与构建时间的区别、规范化输出路径、字体自托管范围和英文 README 所链接指南的实际语言。
