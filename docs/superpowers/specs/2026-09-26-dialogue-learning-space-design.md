# 对话式学习空间设计

## 目标

为有经验的读者提供一个可以直接由 Codex、Claude Code 或其他本地 AI 助手使用的学习入口。读者既可以从真实工程问题出发，也可以按书籍结构学习；AI 应以本书原稿为依据组织对话，而不受预设 Skill、MCP 或固定工作流限制。

## 范围

新增仓库根目录下的 `learning/`，其中只包含 Markdown 文档：

```text
learning/
├── README.md
├── BOOK_MAP.md
└── DIALOGUE_LEARNING.md
```

- `README.md` 说明如何进入目录并开始两种学习方式。
- `BOOK_MAP.md` 提供四部分的职责、章节地图、问题到章节的定位和可选学习路径。
- `DIALOGUE_LEARNING.md` 将本书的内容原则转译为对话质量要求，明确引用、边界和追问的方式。

根目录中文 README 增加一个入口链接，帮助读者发现该目录。

## 非目标

- 不增加专属 Skill、MCP、系统提示词、启动脚本或模型供应商配置。
- 不把 AI 对话嵌入阅读网站，也不保存读者会话。
- 不复制书籍正文；学习空间只负责导航和对话语境。

## 设计理由

书稿、目录和学习文档均为开放的 Markdown。任何本地助手都能读取它们并结合读者的问题组织解释，因此以清晰的文件结构提供共同语境，比在某个工具中硬编码教学步骤更可移植，也保留模型按问题调整深度的能力。
